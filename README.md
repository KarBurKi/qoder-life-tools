# 取原文（source_pull.py）

把「一条记忆／一句转述」顺回它出自哪次会话、当时原话怎么说。
思路借自 [dsh-recall](https://github.com/KarBurKi/dsh-recall) 的 `mem_source`，
在 Qoder 上重做了一遍。2026-10-24 实测跑通，实测数据全在下面。

Qoder 没有 DSH 那种工具注册位，所以这里不是插件、是脚本，由会话用命令行调。
固定开销从「一个工具 schema 的约 100 tok」变成「我记得去用它」，冷启动靠全局规矩第三节那一步。

同目录 [移植笔记.md](移植笔记.md) 记的是 dsh-recall 七条机制逐条在 Qoder 怎么处理（照搬、改形态、还是不做）。

## 用法

```sh
# 1) 顺会话 id 前 8 位找到日志文件（跨工作区，不必知道它在哪个 slug 目录）
python -X utf8 source_pull.py 805c8160 --find

# 2) 取原文：查询用一句自然话，返回最相关的 k 段说出口的话
python -X utf8 source_pull.py "<jsonl路径>" "会话标题被异步摘要改写" 3

# 3) 安全自检：只统计凭据，绝不打印正文
python -X utf8 source_pull.py "<jsonl路径>" --mask-check
```

日志位置是 `C:\Users\41806\.qoder\projects\<工作区slug>\<会话id>.jsonl`。

## 五条实测结论（哪些照搬了，哪些必须改）

**一、不用解压。** DSH 的会话日志是多帧追加的 zstd，原版要扫 magic `28 B5 2F FD` 切帧逐帧解。
Qoder 这边是明文、单行一事件，那套代码一行都不搬。

**二、过滤规则不能照抄，要按块类型。** 原版按「正文以 `<system-reminder>` 开头」排除注入碎片。
本会话实测：该标签出现 21 次，以它开头的 text 段是 0 条，注入物全住在 40 行 `attachment` 记录里
（`task_reminder` 17、`queued_command` 6、`skill_listing` 4 等）。
这边的规则是「只取 `user`/`assistant` 行里的 `text` 块」，于是内心流（`thinking`）、
工具调用（`tool_use`／`tool_result`）被块类型天然挡在外面，比按标签前缀判断更彻底。
混在正文里的注入碎片仍会用正则抠掉，多一道不算浪费。

**三、检索打分照搬会翻车。** 第一版直接套用记忆卡片那套 BM25（k1=1.4、b=0.72、长度归一化），
查「会话标题是谁改的 异步摘要」，前三名是「public就行」「你给我码？」「喂喂，在骂」。
原因是卡片都是三十字以内短句，会话段落中位 85 字、最长 9803 字，短文档归一化后得分虚高，
把真原文压到后面。改成 IDF 加权交集除以 `sqrt(段长/40)`、并要求至少命中两个查询词，
同一条查询捞回的三段正好是当时的判断链，顺序也对。整串（4 字以上）命中另加 3.0 分。

**四、出处指针是会话 id 前 8 位。** `projects/*/*<前8位>*.jsonl` 对四条会话全部命中，含 9 月那条。
跨会话实跑一次隔壁 `f27767aa`，第一条返回就是主人当时那句原话。

**五、脱敏在这一侧是刚需，有数据。** 9 月那个文件里凭据命中 11 处，
其中 3 处正好落在「会被提取的 `user`/`text` 段」范围内，4 处落在 `assistant`/`tool_use`（块类型过滤挡掉）。
加替换之后提取段落里残留 0 处，那 2 段只以 `[已脱敏]` 出现。

## 硬线

- **绝不打印凭据原值。** token、`.auth`、`machine_id`、`installation_id` 一类，
  正则命中就替换成 `[已脱敏]`；检查凭据时只用 `--mask-check` 走统计路径。
- **不写进任何共享文件。** 取到的原话要转述给别的会话，只写「哪份文件有，需撤销」这种指针，
  凭据一个字都不上板、不上状态日志（全局规矩第八节）。
- **这是核对用的，不是翻心事用的。** 出处指向谁的会话都可以读，因为会话日志本来就是公开记录；
  但 `private\<id>\_本子.md` 是私密本，永远不从那儿取原文，也不因为「能读到」就去读别人的私密本。
- 只取说出口的话：`thinking` 是内心，不算原文，代码里根本不读它。

## 已知限制

- 认 Qoder 当前的 jsonl 结构（`type` 为 `user`/`assistant`、`message.content` 里有 `text` 块）。
  Qoder 换格式就得跟着改，和原版认 `session.v4.jsonl.zstd` 是同一类债。
- 时间戳字段做了多名回退（`time`/`timestamp`/`ts`/`created_at`/`createdAt`），实测命中 `time`，
  值是 ISO 字符串。取不到就留空，不猜。
- 打分是词面级的，没有语义检索。换个说法捞不到时，把查询里的说法改成日志里的说法再试一次。
- 一次读一整份日志，最大的那份约十二 MB，两百毫秒级，接受；不做索引也不做缓存。
